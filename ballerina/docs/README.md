Project-level design and planning documents that previously lived here
have moved to
[`a2a-project-resources/a2a-ballerina-design`](https://github.com/Anuja-jayasinghe/a2a-project-resources/tree/main/a2a-ballerina-design):

should only ever contain the module's own API spec, not project history.
